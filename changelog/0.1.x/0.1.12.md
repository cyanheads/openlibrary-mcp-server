# 0.1.12 — 2026-06-04

## Fixed

- **`getWork`, `getAuthor`, `getEditions`, `getSubject`** (service) — methods now return `null` on not-found instead of throwing `notFound()` directly ([#6](https://github.com/cyanheads/openlibrary-mcp-server/issues/6)).
- **`openlibrary_get_work`, `openlibrary_get_author`, `openlibrary_get_editions`, `openlibrary_get_subject`** (handlers) — null return from service now routes through `ctx.fail('not_found', …)` so `data.reason` is populated on the wire and the typed error contract is exercised ([#6](https://github.com/cyanheads/openlibrary-mcp-server/issues/6)).
- **`getAuthorWorks`** (service) — Open Library returns HTTP 404 + `{}` for non-existent author IDs; `fetch()` does not inspect response status, so the empty object was silently treated as a valid response (`total: undefined, works: []`). Guard added: `size === undefined && entries === undefined` → return `null` ([#5](https://github.com/cyanheads/openlibrary-mcp-server/issues/5)).
- **`openlibrary_get_author_works`** (handler) — null from `getAuthorWorks` now throws `ctx.fail('not_found', …)`, making the declared error contract live ([#5](https://github.com/cyanheads/openlibrary-mcp-server/issues/5)).
- **`openlibraryAuthorResource`, `openlibraryWorkResource`** (resources) — same null-guard + `notFound()` pattern applied so resource handlers also surface `NotFound` on missing IDs.
- Tests updated across all affected tools and resources to mock `null` returns and assert `data.reason === 'not_found'`; new edge-case tests added for `openlibrary_get_editions`, `openlibrary_get_subject`, and `openlibrary_get_work`.
