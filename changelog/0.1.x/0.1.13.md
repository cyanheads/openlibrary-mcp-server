# 0.1.13 — 2026-06-12

## Added

- **`totalCount` enrichment** — `openlibrary_search_books`, `openlibrary_search_authors`, `openlibrary_get_subject`, `openlibrary_get_author_works`, and `openlibrary_get_editions` now surface the upstream total across all pages via `ctx.enrich.total()`, so an agent paging a result set knows how many records exist beyond the current window.
- **Server identity** — `createApp()` sets `name` and `title` to `openlibrary-mcp-server`, forwarded to the `initialize` response and `/.well-known/mcp.json` (was relying on the scoped package-name fallback).
- **Docker `HEALTHCHECK`** — container probes `/healthz` every 30s; the image also carries an `org.opencontainers.image.version` OCI label fed by a new `APP_VERSION` build arg.
- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into `bundle`; runs `mcpb clean` then strips dependency-shipped `skills/`, `.claude/`, `.agents/`, and stray `SKILL.md` entries that root-anchored `.mcpbignore` patterns cannot reach inside `node_modules/`.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21 → ^0.10.6` — adopts the `enrich.total()` convention; the bump carries `@modelcontextprotocol/ext-apps` `1.7.3 → 1.7.4` and `hono` `4.12.23 → 4.12.25` transitively.
- **`.mcpbignore`** — `skills/`, `.claude/`, `.agents/` patterns are now root-anchored (`/skills/` etc.) so they exclude only the project-root trees, not same-named directories nested under dependencies.
- **`check-framework-antipatterns.ts`** — adds a consumer-facing `z.coerce.boolean()` rule (the env-flag footgun: `Boolean("false")` is `true`; use `z.stringbool()`), and skips comment lines so a documented mention of an antipattern is not flagged as a usage.
- **Vendored skills** resynced to the installed framework version; `CLAUDE.md` / `AGENTS.md` document the server-identity fields and the `z.stringbool()` env-boolean rule.
