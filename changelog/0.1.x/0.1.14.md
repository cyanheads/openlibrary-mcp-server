# 0.1.14 — 2026-06-15

## Added

- **Server `instructions`** — `createApp({ instructions })` now sends session-level orientation on every `initialize`: the `openlibrary_*` toolset, the keyless API, suffix-typed IDs (works `OL…W`, editions `OL…M`, authors `OL…A`; editions also resolve by ISBN), the canonical search → work → editions/edition flow, and the `openlibrary_get_cover_url` always-200 / 1×1-placeholder behavior.

## Changed

- **Plugin display identity** — the agent-facing identity fields are now the unscoped `openlibrary-mcp-server` (was `@cyanheads/openlibrary-mcp-server`): the `name` and `mcpServers` key in `.claude-plugin/plugin.json`, and the server key in `.codex-plugin/mcp.json` plus `interface.displayName` in `.codex-plugin/plugin.json`. The npm install `args` stay scoped (`@cyanheads/openlibrary-mcp-server`) — they reference the published package name.
- **`vitest`** (dev) `^4.1.8 → ^4.1.9`.
