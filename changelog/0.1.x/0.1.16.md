# 0.1.16 — 2026-06-20

Framework-maintenance release — no server behavior changes. Adopts `@cyanheads/mcp-ts-core` `^0.10.6 → ^0.10.9` and the tooling it ships.

## Added

- **`check-dependency-specifiers` devcheck step** — new `scripts/check-dependency-specifiers.ts`, hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` dependency sections and `bun.lock`'s `workspaces` map. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **Plugin-manifest checks in `lint:packaging`** — validates `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` for non-empty descriptions, unscoped display identity, and the full-package install arg; gated by the new `devcheck.config.json` `packaging.pluginManifests` flag (default on). ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))

## Changed

- **`.codex-plugin/plugin.json`** — populated the previously-empty `interface.longDescription` and set `interface.category` to `research`, satisfying the new packaging lint.
- **Fresh-scaffold devcheck guards** — `scripts/devcheck.ts`, `scripts/build-changelog.ts`, `scripts/check-framework-antipatterns.ts`, and `scripts/check-skill-versions.ts` re-synced from the framework: git-dependent checks skip when `.git` is absent, the changelog check exits cleanly on an empty changelog tree, and a `SKILL.md` deleted from the worktree no longer crashes the version check. ([cyanheads/mcp-ts-core#237](https://github.com/cyanheads/mcp-ts-core/issues/237), [#242](https://github.com/cyanheads/mcp-ts-core/issues/242), [#243](https://github.com/cyanheads/mcp-ts-core/issues/243))
- **Framework skills re-synced** — `add-tool`, `api-canvas`, `api-config`, `api-context`, `api-telemetry`, `git-wrapup`, `orchestrations`, and `polish-docs-meta` updated from `mcp-ts-core` `^0.10.9` (`api-context` documents the new `ctx.content` collector). ([cyanheads/mcp-ts-core#238](https://github.com/cyanheads/mcp-ts-core/issues/238), [#239](https://github.com/cyanheads/mcp-ts-core/issues/239))
- **`@cyanheads/mcp-ts-core`** `^0.10.6 → ^0.10.9`.
- **`@types/node`** (dev) `^25.9.3 → ^26.0.0`.
