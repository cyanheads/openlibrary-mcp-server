# 0.2.4 — 2026-08-24

## Changed

- **HTTP transport** supports protocol revision 2026-07-28 while existing 2025-era sessions remain supported.
- **Tool inputs** reject unknown top-level arguments instead of silently stripping them; send only schema-declared keys.
- **Advertised tool output schemas** include the error envelope, letting clients validate error results.
- **HTTP session mode defaults to `stateless`** rather than resolving `auto` to a persistent per-connection session. This disables the legacy multi-round-trip input shim for 2025-era HTTP clients — not used by any tool here.
- **`openlibrary_get_edition`'s "Authors" heading** reads "Authors (recorded on this edition)" to distinguish it from the parent-work fallback rendered below it.
- **Runtime image** uses Bun 1.4.0 and omits optional peer dependencies from production installs.
- **Community health files** add contributing and conduct guidance, and route vulnerability reports to `security@caseyjhand.com`.
