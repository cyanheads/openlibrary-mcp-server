# 0.4.0 — 2026-10-26

## Added

- Add the openlibrary-guide skill, available through MCP skill discovery and skill:// resources.

## Changed

- **Request limits** clamp oversized pages to 100 and process the first 50 distinct edition identifiers, returning every remainder in `unprocessed`; `OPENLIBRARY_CLAMP_LIMITS=false` restores strict bounds ([#51](https://github.com/cyanheads/openlibrary-mcp-server/issues/51), [#53](https://github.com/cyanheads/openlibrary-mcp-server/issues/53)).
- **Install tooling** adopts Agent Plugins root manifests, published-skill validation, and updated framework skills.

## Fixed

- **Text output** preserves complete arrays, exact numbers, sparse values, and literal catalog text across tools; cover and reading URLs render as images and links ([#13](https://github.com/cyanheads/openlibrary-mcp-server/issues/13)).
- **Book search** retains the provider-selected edition and matching-edition count; actual upstream HTTP 422 failures expose safe validation messages and recovery ([#49](https://github.com/cyanheads/openlibrary-mcp-server/issues/49), [#44](https://github.com/cyanheads/openlibrary-mcp-server/issues/44)).
- **Edition metadata** preserves all cataloged languages plus physical format and printing statements in list and detail responses ([#47](https://github.com/cyanheads/openlibrary-mcp-server/issues/47), [#50](https://github.com/cyanheads/openlibrary-mcp-server/issues/50)).
- **Author and subject lookups** refuse empty author IDs without fetching, trim subjects before normalization, and reject blank subjects locally ([#46](https://github.com/cyanheads/openlibrary-mcp-server/issues/46), [#48](https://github.com/cyanheads/openlibrary-mcp-server/issues/48)).
- **Resources** return stable `not_found` reasons and recovery guidance for missing works and authors ([#52](https://github.com/cyanheads/openlibrary-mcp-server/issues/52)).
- **MCPB cleanup** preserves SDK runtime skill modules while removing dependency package-root agent documentation and build-only files.
